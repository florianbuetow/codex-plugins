# Onboarding

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Project onboarding skill that orients AI agents by gathering context from project instructions, git state, issue trackers, and build systems to produce a concise status briefing with suggested next steps.

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add onboarding@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

# Solid Principles

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Analyze code for violations of the SOLID principles of object-oriented design (Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion)

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add solid-principles@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

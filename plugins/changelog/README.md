# Changelog

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Generate and maintain CHANGELOG.md files from git commit history using Keep a Changelog format with semantic versioning. Creates new changelogs or appends updates to existing ones.

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add changelog@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

# Beyond Solid Principles

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Analyze code and architecture for violations of ten system-level software design principles: Separation of Concerns, Single Responsibility (system-level), DRY, Law of Demeter, Loose Coupling / High Cohesion, Evolvability, Resilience, KISS, Principle of Least Surprise, and YAGNI

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add beyond-solid-principles@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

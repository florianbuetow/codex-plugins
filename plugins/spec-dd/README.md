# Spec Dd

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Specification-driven development workflow skill. Orchestrates a spec-first discipline: frame a one-page Product Spec (problem, falsifiable bet, success criteria, evaluation) that replaces the PRD, then write behavioral specifications, derive test scenarios, plan implementation, and verify alignment across all artifacts and code. Acts as a workflow navigator with advisory quality gates between phases.

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add spec-dd@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

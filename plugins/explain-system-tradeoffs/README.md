# Explain System Tradeoffs

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Reverse-engineer distributed system tradeoffs from code, configuration, and architecture artifacts. Analyzes six axes: Consistency & Availability, Latency & Throughput, Data Distribution, Transaction Boundaries, Resilience & Failure Isolation, and Observability, Security & Cost.

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add explain-system-tradeoffs@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.

# Orchestrator

> Generated for Codex from the canonical source plugin. Run `just update` at the marketplace root to refresh it.

Produces evidence-based model routing plans: maps each task unit to the best-suited AI model (Codex, GPT, Gemini, open-weight) using a 30-category task taxonomy, decision rules, and per-unit rationale, context briefing, and failure-mode warnings.

## Install with Codex

Register the repository marketplace with `codex plugin marketplace add .`, then run `codex plugin add orchestrator@florianbuetow-codex-plugins` or install it from **Florian Buetow Codex Plugins** in the Plugins Directory. Invoke its workflows with `$<skill-name>`.
